# Ice Cream Builder
Team Java Project 2

An interactive Java application for building custom ice cream sundaes!

## Features

- Choose from 6 delicious ice cream flavors
- Add up to 8 different toppings
- See the total price of your custom sundae
- Interactive command-line interface

## How to Run

### Prerequisites
- Java Development Kit (JDK) 8 or higher

### Compile and Run

1. Compile the application:
   ```bash
   ./compile.sh
   ```

2. Run the application:
   ```bash
   ./run.sh
   ```

   Or run directly:
   ```bash
   java -cp bin com.icecream.IceCreamBuilder
   ```

## Usage

1. When prompted, select ice cream flavors by entering their numbers
2. Enter `0` when you're done selecting ice cream
3. Select toppings by entering their numbers
4. Enter `0` when you're done selecting toppings
5. View your custom sundae summary with the total price!
